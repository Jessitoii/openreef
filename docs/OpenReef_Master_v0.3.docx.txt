No server. No subscription. No data leaves the device. The model runs on-device via LiteRT-LM, memory is stored locally via sqlite-vec, external integrations connect via MCP, and native Android capabilities are exposed as tools. inference framework for on-device LLMs. It replaced MediaPipe LLM Inference API (now deprecated). Powers Gemini Nano in Chrome, Chromebook Plus, and Pixel Watch. A skill is a folder containing a SKILL.md file with YAML frontmatter and instructions. Skills use progressive disclosure: only metadata loads at startup; full content loads only when the LLM decides to invoke the skill.▸ Skill-Creator — Most Important SkillSkill-Creator is the meta-skill that lets the LLM create new skills for itself. User describes what they want in plain language, Skill-Creator designs the SKILL.md, optionally creates trigger configs and bundled scripts, previews for user confirmation, then registers the skill.05  CONTEXT ENGINE & PROMPT STRATEGY▸ The Core ProblemOpenReef has 30+ skills, 37+ native tools, 20+ MCP tools per connection, memory, conversation history — all competing for the context window. The naive approach produces poor tool selection and wasted tokens.
