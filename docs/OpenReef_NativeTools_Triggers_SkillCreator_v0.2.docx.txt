for itself. The user describes what they want, and Skill-Creator writes the SKILL.md guidance + optional YAML config + registers it.▸ J.1 — What Skill-Creator DoesUser: "I want you to monitor my sleep schedule.       Every morning at 7am, ask me what time I went to sleep       and what time I woke up. Track this and give me a       weekly sleep analysis every Sunday."Skill-Creator:  1. Identifies required tools:     - alarm_set (7am daily trigger)     - alarm_set (Sunday weekly trigger)     - memory_save (store each sleep entry)     - memory_search (retrieve week's entries for analysis)     - notify (prompt user for input)  2. Identifies required MCP: none (fully native)  3. Writes SKILL.md  4. Creates trigger configs  5. Registers skill → shows preview → user confirms  6. Skill is now active. Triggers registered. Done.▸ J.2 — Skill-Creator ProcessPhase 1: UNDERSTAND  - Parse user intent  - Identify: what triggers this? what tools needed? what data stored?  - Ask clarifying questions if ambiguous  - Check for conflicts with existing skillsPhase 2: DESIGN  - Draft SKILL.md content  - Define trigger configs (if needed)  - Define memory schema  - Define skill state schemaPhase 3: PREVIEW  - Show user the skill design in plain language  - "Should I create this skill?"Phase 4: CREATE  - Write SKILL.md to skills/ directory  - Register triggers via TriggerSystem  - Register skill in SkillRegistry  - Inject into LLM system prompt immediatelyPhase 5: TEST (optional)  - User can say 'test this skill'  - Skill-Creator runs a dry-run simulation  - Shows what would happen without real side-effects▸ J.3 — Skill Output Format· SKILL.md (required)# {Skill Name}> {one-line description}## Triggers{when this skill activates}## Tools Used{list of tools this skill relies on}## Behavior{step-by-step instructions for the agent}## Memory Schema{what data is stored, in what format}## Examples{concrete input → output examples}## Edge Cases{what to do when things go wrong}· skill.yaml (optional)id: sleep_trackername: Sleep Trackerversion: 1.0.0author: userdescription: Track daily sleep schedule and give weekly analysistriggers:  -
